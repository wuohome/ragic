# 360 環景頁產生器

把一疊 360 環景照（equirectangular，寬高比 2:1，例如 LINE 傳來的 `S__xxxxx.jpg`）打包成
**一個可以拖曳環顧的單一 HTML 檔**。

## 為什麼需要這個

360 相機拍的照片經過 LINE／通訊軟體轉傳後，檔案裡的全景標記（XMP GPano）會被剝掉。
少了那段標記，Google 相簿、Facebook 都不會把它當環景，只會顯示成一張左右拉長、天花板扭曲的怪圖。
這支腳本不依賴那段標記，直接照 2:1 的投影規則把圖貼回球面上重畫，所以轉傳過的照片也能正常看。

## 用法

```powershell
cd tools\pano
.\build-pano.ps1 -Source "C:\Users\Joan\Downloads\某某案場" -Out "..\..\pano\某某案-a1b2c3.html"
```

場景名稱放在來源資料夾的 `scenes.json`（UTF-8）：

```json
{
  "title": "雙城街 2 樓",
  "scenes": [
    { "file": "S__27869217_0.jpg", "name": "入口主房", "desc": "進門第一間，連接走道與衛浴" },
    { "file": "S__27869219_0.jpg", "name": "主房衛浴", "desc": "主房內側的洗手台與馬桶" }
  ]
}
```

`scenes.json` 的順序就是縮圖列與上一張／下一張的順序，建議照實際參觀動線排。
沒放 `scenes.json` 也能跑，會自動抓資料夾裡所有 2:1 的圖，依檔名排序，名字叫「場景 1、場景 2…」。

## 產出的頁面

- 滑鼠拖曳環顧、滾輪縮放；手機可觸控拖曳與雙指縮放
- 底部縮圖列切換場景，左右方向鍵也可切換
- 圖片全部以 base64 內嵌，**不連任何外部網站**，離線與內網都能開
- 已加 `noindex,nofollow`，不會被搜尋引擎收錄
- 用原生 WebGL 畫，沒有任何第三方函式庫

## 檔名規則（重要）

發給客戶或同仁的網址一旦送出就是永久網址，**不要改檔名、不要加版號**。
內容要更新就就地覆蓋同一個檔名再 push；要退版用 `git revert`，不要叫人換連結。

新頁面請放在 repo 根目錄的 `pano/`，檔名帶一段隨機碼（例如 `shuangcheng-2f-b5y8dq.html`），
這樣網址猜不到、也不會被搜尋引擎翻出來，只有拿到連結的人打得開。
`pano/` 底下沒有 index，直接瀏覽目錄會是 404。

## 參數

| 參數 | 預設 | 說明 |
|---|---|---|
| `-Source` | 必填 | 放環景照的資料夾 |
| `-Out` | 必填 | 輸出的 HTML 路徑 |
| `-Title` | 取自 `scenes.json`，再取資料夾名 | 顯示在頁面左上角的標題 |
| `-Width` | 2048 | 環景貼圖寬度，**必須是 2 的冪**，否則左右接縫會出現破圖 |
| `-Quality` | 82 | JPEG 品質。8 張照片約 2.7 MB，調高會變大 |

## 已知限制

- 只吃 2:1 的 equirectangular 照片。魚眼原始檔（雙半球）不支援，要先用相機的軟體轉出全景圖
- 沒有陀螺儀視角、沒有場景之間的熱點跳轉
- 單檔會隨場景數線性變大，超過 20 個場景建議改成外部圖片檔而非 base64 內嵌
